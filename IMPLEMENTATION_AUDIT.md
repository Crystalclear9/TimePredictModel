# Implementation audit

The source implements the association reducer, strict argument/features contract, semantic action families, XGBoost direct log-time replay models, checksum-checked packages, and staged publication. The replay package is synthetic (`observed_replay`) and is permanently marked `production_releasable=false`.

The latest WSL evidence is generated by `scripts/verify_wsl.py` and bound to a source digest in `outputs/final-audit.json`. It confirms compilation, the prepared-to-waiting lifecycle reducer, and static SGLang patch markers. The WSL image currently has neither pytest/project dependencies nor `redis-server`, so Redis Streams/CAS, the real encoder, and the full test suite remain unverified rather than being reported as passes.

Formal production samples require `label_kind=sglang_return_observed`, `association_mode=tool_call_id`, `tool_call_id_verified=true`, both server and Agent boundary timestamps, and source event evidence. Proxy and synthetic datasets cannot enter a production training or promotion path. Exgentic, AgentTrace, Trace Commons, and Betterwright reports remain independent proxy experiments.

The following require target-server evidence and are intentionally `not_verified_server`: GPU SGLang execution, multi-machine chrony, Redis cluster failover, entry P99 <=2 ms, and throughput loss <=1%. No public dataset is used to claim the formal `t_return - t_out` target.
